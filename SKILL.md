# Brand Website Copy Generator

## Purpose
This Skill takes messy, informal product notes and turns them into clean,
consistent website copy — every time, in the same voice, without needing
to re-explain the brand from scratch.

## When to use this Skill
- A new product is being added to the website
- An existing product description needs a refresh
- Marketing copy needs to match the site's tone before publishing

## Required inputs
Before generating copy, gather:
1. **Product name**
2. **Core problem it solves** (in plain words, from the founder)
3. **Key ingredients / what's inside**
4. **How it's used / how long results typically take**
5. **Sizes and prices**
6. **Brand voice** — default: premium & minimal (short sentences, no
   exclamation-heavy language, no emoji, confident but understated)

If any of these are missing, ask for them before writing. Do not invent
ingredients, prices, or timeframes.

## Rules (non-negotiable)
1. **No unverified claims.** Never state a specific percentage, cure, or
   guaranteed outcome (e.g. "reduces hair fall by 40%") unless the founder
   has confirmed it is backed by real, measured data. Default to honest,
   experience-based language instead ("many customers notice softer,
   thicker-feeling hair over consistent use").
2. **No medical/therapeutic promises.** Avoid words like "cures,"
   "treats," or "guaranteed" for anything related to health or the body.
3. **Consistent structure every time** (see Output Format below) — this
   is what makes it a Skill rather than a one-off prompt.
4. **Match the brand voice exactly.** For premium & minimal: no emoji,
   no exclamation marks, short punchy sentences, confident and calm tone,
   let the ingredients speak for themselves rather than over-selling.
5. **Never fabricate pricing or sizes** — use only what was provided.

## Output Format
Always generate these sections, in this order:

1. **Hero headline** (under 8 words)
2. **Subheadline** (one sentence, states the real problem it addresses)
3. **Why it works** (3–5 short bullet benefits, no emoji, no absolute claims)
4. **What's inside** (ingredient list, plain sentence framing — not a raw list)
5. **How to use / what to expect** (honest, time-based language: "with
   consistent use over several months")
6. **Pricing** (clean list, size → price)
7. **Closing line** (short, confident, one line — no hard sell)
